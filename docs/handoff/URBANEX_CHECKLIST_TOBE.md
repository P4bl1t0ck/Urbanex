## T1 · Captación de propiedades
- [ ] El propietario entrega la información del inmueble y el asesor verifica la documentación.
- [ ] El asesor registra la propiedad y queda como captador y responsable inicial.
- [ ] El asesor carga la documentación inicial en el expediente digital.
- [ ] El asesor realiza el avalúo comercial con el motor paramétrico.
- [ ] Se presenta el avalúo al propietario y se negocia el precio de captación.
- [ ] La captación se formaliza con el contrato de corretaje.
- [ ] Se publica la propiedad y pasa a estado Disponible.

## T2 · Marketing y generación de prospectos
- [ ] Se crea y centraliza la ficha digital del inmueble con multimedia y descripción estructurada.
- [ ] El portal público muestra automáticamente la propiedad disponible en el catálogo.
- [ ] El asesor publica el inmueble en Marketplace de Facebook con enlace directo a la ficha.
- [ ] Se amplía alcance mediante promoción digital.
- [ ] Se genera contenido atractivo en redes sociales para dirigir tráfico al ecosistema digital.
- [ ] Se reciben manifestaciones de interés vía formularios o mensajería conectada al sistema.

## T3 · Gestión de contacto y citas
- [ ] La captación manual o digital crea el contacto y abre la oportunidad comercial.
- [ ] El sistema conserva conversaciones iniciales y gestiona la validación del número telefónico.
- [ ] La propiedad reservada bloquea contacto directo y habilita el formulario de interés.
- [ ] El formulario crea el contacto y abre la oportunidad en seguimiento.
- [ ] El sistema notifica al asesor y envía mensaje de bienvenida por WhatsApp Business.
- [ ] Se registra la cita y se actualiza la oportunidad a Visita Programada.
- [ ] La visita se registra con resultado, motivo y trazabilidad.
- [ ] Si no hay interés, se cierra con motivo; si hay interés, se avanza a venta o arriendo.

## T4 · Venta de propiedades
- [ ] El cliente expresa interés y el asesor actualiza la oportunidad comercial.
- [ ] Se negocia precio, forma de pago y condiciones.
- [ ] Si hay acuerdo, se registra la reserva y se bloquea la propiedad.
- [ ] Se formalizan acuerdos preliminares y se adjuntan documentos de respaldo.
- [ ] Si fracasa la reserva, el Administrador ejecuta la reversión con motivo.
- [ ] Se registran pagos, escritura y cierre.
- [ ] El Administrador revisa la cola de cierre y confirma el cierre definitivo.

## T5 · Arriendo de propiedades
- [ ] El arrendatario solicita la propiedad y la oportunidad se actualiza.
- [ ] Se realiza la visita y se documenta la respuesta del cliente.
- [ ] Si hay interés formal, se cargan requisitos del postulante.
- [ ] Se valida la documentación y se registra la decisión del propietario.
- [ ] Si hay acuerdo preliminar, se registra la reserva y se bloquea la propiedad.
- [ ] Si falla la negociación, se ejecuta la reversión con motivo.
- [ ] Se formaliza el contrato de arriendo y se cierra la oportunidad.

## T6 · Avalúo comercial
- [ ] Se cargan y validan las características del inmueble.
- [ ] El sistema compara la propiedad con comparables y calcula el valor sugerido.
- [ ] El asesor calibra y aprueba el avalúo.
- [ ] El precio aceptado queda asociado a la propiedad o a la negociación posterior.

## T7 · Gestión documental
- [ ] El Asesor carga los archivos del propietario o cliente.
- [ ] El Administrador valida autenticidad y vigencia de los documentos.
- [ ] Los documentos se almacenan y clasifican de forma segura.
- [ ] Se permiten consultas seguras con permisos por rol.
- [ ] El sistema emite alertas por documentos faltantes o vencidos.

## T8 · Gestión administrativa de cartera operativa
- [ ] El Administrador visualiza la cartera activa de propiedades y oportunidades.
- [ ] El sistema muestra la carga operativa por asesor.
- [ ] El Administrador selecciona la propiedad u oportunidad.
- [ ] El Administrador reasigna el responsable.
- [ ] El sistema actualiza la asignación inmediatamente.

## Criterio de uso
- [ ] Cada paso se confirma con la operación real del negocio.
- [ ] Si hay diferencia con la tesis, se documenta y se prioriza la tesis como criterio final.
- [ ] El estado operativo se valida con la evidencia y con la trazabilidad del proceso.
